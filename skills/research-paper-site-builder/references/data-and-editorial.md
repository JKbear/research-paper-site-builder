# 数据契约、科学证据与发布边界

以下是新站的建议契约；不是 EQHOT 原始 JSON 的逐字段复制。实现可以调整字段，但必须保留等价含义。

## 数据分层

| 层 | 关键字段 | 存储与边界 |
|---|---|---|
| 来源配置 | id、name、ISSN、mode、source.type/url/status、verifiedAt、evidenceUrl | 配置或派生 journals；不是论文事实 |
| 原始候选 | DOI、题名、作者、journalId、原文链接、来源URL、采集时间、摘要及来源、日期及依据 | 私有 data；未审核不公开 |
| 自动建议 | 范围命中、主题、类型、规则/模型版本、输入指纹、理由、证据摘录、错误 | 私有独立记录；不覆盖人工决定 |
| 人工决定 | DOI、include/hold/exclude、editor、reviewedAt、reason、guide、evidenceLevel、source、history | 人工优先；暂缓和排除不删除原始候选 |
| 精选签发 | 研究问题、增量、读者、推荐短评、解释边界、证据与签发信息 | 单独状态；普通收录不自动签发 |
| 公开投影 | 标识、DOI、原题、作者、期刊、主题、可展示日期与依据、原创导读、证据标签、出版警示 | 白名单构建；剥离内部理由、凭据、未授权摘要 |

DOI 归一化：去除 doi.org/doi: 前缀、解码、去包裹标点、统一大小写。保留 DOI 有效组成字符；无效或暂缺 DOI 的发现可在私有队列保留，不给它伪造 DOI。公开是否允许无 DOI 条目由用户范围确定，若允许则明确采用其他稳定标识。

## 状态不要混为一个 published

分别表示三条轴：

1. 范围决定：未决定、include、hold、exclude。
2. 证据/技术状态：题名可用、摘要可用、全文可用、待补证、来源失败、审核技术失败。
3. 发布状态：不满足门槛、可构建、已打包、已部署且核验；另设精选未签发/已签发。

人工 include 是持久决定。后续403、元数据刷新或暂时缺证，只进入“已通过，等待补证”，不要求用户重复通过。人工决定不能替代 DOI 身份或证据核验；冲突时保持决定，阻止依赖缺失证据的发布。自动结果对输入指纹与规则版本绑定，数据改变需重新验证；它不撤销人工决定。

## 日期与身份

- 记录 `date.value`、`basis`（online-publication、publication、doi-registration、unknown）、`precision`、`source` 和核查时间。只有年份/月时不拼造1月1日或当月1日。
- 官网首发、卷期日期、Crossref登记日期和采集日期分别保存。未来卷期不能作为“今天新发表”；使用登记日期展示必须明确标注，并从按发表时间的周报主栏区分。
- 官网原文 DOI、题名、期刊/ISSN核对优先。摘要中的相关词、第三方搜索结果或能解析的 DOI 链接，不足以证明候选与原文是同一篇。
- 类型区分研究、综述、评论、回复、新闻、更正、撤稿公告等；类型白名单按用户研究习惯配置。评论/回复若无摘要，可由可信正文支撑，不能把站点导航拼成摘要。

## 导读与自动审核

证据等级建议 `T=题名`、`A=摘要`、`F=全文`，界面直接说明依据。T级只能描述题名显式内容，不推断方法性能、主要结果或科学突破；A级不宣称读过全文。保留来源与时间。精选通常要求 A/F 与编辑签发，具体要求可随用户目标收窄。

人工模式先跑通。不强制模型、某家供应商、某种CLI或登录方式。用户需要模型审核时：

1. 独立的 judge 接口读取已取得且已核对身份的证据，输出结构化范围、导读、理由、证据摘录。
2. 独立复核请求读取原始证据检查初审；同一模型两轮不称作独立科学权威。
3. 程序校验枚举、长度、DOI、引文逐字存在、字段完整、输入指纹和类型/日期门槛。模型说 approve 不等于放行。
4. 提示词、期刊内容和摘要都是不可信输入；不给审核执行器 shell、仓库写权限或部署凭据。保存器用可信代码校验并写入。
5. 缺证、分歧进入待审；认证、配额或超时为技术错误。模型不可用时继续采集并保存候选，不把假导读或缓存旧结果当新审核。
6. 模型授权只在确需自动审核时配置，估算调用预算；不复制原站登录资料，不假设本机登录可直接在云端使用。

公开内容采取保守字段投影：元数据、链接、原创导读与证据标签。取得摘要不代表有权转载；逐来源核对许可后再决定展示摘要，不在默认生产包包含全文PDF、私有引文集合或后台审核记录。论文撤稿/更正等使用有来源的公告与时间；“未核查”不代表没有公告。

## 构建门槛

论文：范围决定可收录、身份一致、元数据满足展示要求、有相应证据标签的导读、无阻止发布的公告状态。暂缓与普通待审可排除单篇而构建其余合格子集。

整站：数据结构错误、来源达到配置的失败/陈旧门槛、未恢复的审核技术错误或版本快照冲突要阻止自动生产发布并保存旧版。EQHOT 曾采用48小时健康阈值；新站应按采集频率配置。若要在个别来源故障时发布其余来源，须明确范围、告警与“该刊更新不完整”标识，不能静默降级成全站正常。
